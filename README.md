# EXIM Super App Product OS

Единый источник правды по продукту **EXIM Super App**. Это текущее рабочее название; финальное имя и бренд остаются открытым вопросом OQ-047.

EXIM Super App проектируется как независимая multi-tenant SaaS-платформа для логистики. Первый полноценный tenant и пилот Private Operating OS — `exim.kz`, но платформенный уровень нельзя жёстко привязывать к одной компании. Будущая структура владения и оператора платформы пока не утверждена.

Платформа объединяет два обязательных продуктовых контура:

1. **Private Operating OS** — приватная рабочая система логистической компании: клиенты, запросы, ставки, коммерческие предложения, договоры, перевозки, рейсы, tracking, документы, задачи и финансы.
2. **EXIM Exchange** — рабочее название отдельного бизнес-модуля поиска грузов и свободного транспорта по принципу ATI.SU для грузовладельцев, перевозчиков и логистических компаний.

Репозиторий **не содержит код рабочего приложения**. Здесь находятся решения, гипотезы, процессы, роли, карта продукта, требования, MVP, roadmap, аудит реализации, ТЗ интегратору и открытые вопросы.

## Приоритет источников

1. Подтверждённые решения владельца продукта.
2. Product Foundation и реестр решений этой версии.
3. Требования `REQ-*` и критерии приёмки.
4. Гипотезы и открытые вопросы — не считаются утверждёнными решениями.
5. Живое приложение показывает факт реализации, но само по себе не меняет требования.

Июльская версия Product OS сохраняется в Git-истории. Версия `0.5.0 — draft` формализует более новое платформенное направление от 2026-08-26 и результаты live-аудита от 2026-09-04.

```bash

```

## Интегратору

- Первое текущее ready-задание: [TASK-2026-001 — Foundation Gate](docs/12-delivery/tasks/TASK-2026-001-foundation-gate.md).
- Передача в Claude Code: [CLAUDE_CODE_START_PROMPT.md](CLAUDE_CODE_START_PROMPT.md).
- Перед началом записи интегратор указывает точные application repo, base branch, expected HEAD и PR target.
- Код рабочего приложения изменяется в его отдельном репозитории; этот репозиторий хранит Product OS, требования и приёмку.
- Открытые вопросы и `TBD` не дают права самостоятельно придумывать бизнес-правила.
- Подробная сдача возвращается в этот репозиторий через [report PR](docs/12-delivery/reports/README.md); после review здесь появляется следующая задача.
