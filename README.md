# EXIM Product OS

Единый источник правды по цифровому продукту EXIM.

Этот репозиторий **не является кодом рабочего логистического приложения**. Он содержит видение, процессы, роли, карту страниц, статусы, wireframe, MVP, ТЗ интегратору и открытые вопросы.

## Быстрый запуск

Требуется Node.js 22+.

```bash
npm install
npm run docs:dev
```

Проверка сборки:

```bash
npm run docs:build
npm run docs:preview
```

## Публикация

В репозитории есть workflow GitHub Pages. После загрузки в GitHub выберите `Settings → Pages → Source: GitHub Actions`.
