# REQ-007 — Объявления грузов и транспорта

## Статус и цель

**Статус:** draft для Launch MVP.<br>
**Цель:** позволить организации размещать груз или свободный транспорт без раскрытия Private OS; конкретная механика публикации остаётся draft.

## Объекты

- `CargoListing`;
- `TransportListing`.

## Минимальный профиль участника — draft Launch baseline

Каждое объявление связано со стабильным профилем organization. Минимальный публичный слой содержит display name, разрешённые capabilities и собственные active listings. Только поля из явного public allowlist попадают в payload. Наличие базового профиля не означает KYC или verification; badge/status проверки, жалобы и moderation появляются только если отдельно утверждён conditional REQ-010.

## Правила

- владелец — organization;
- capabilities груз/транспорт могут совмещаться;
- создание требует entitlement и разрешённого membership;
- поддерживаются авто, ЖД, море, авиа и мультимодальные объявления; контейнерные параметры применяются по сценарию;
- черновик не виден в поиске;
- предпросмотр публичных полей — предлагаемый safe default;
- использование приватного QuoteRequest не входит в требование до закрытия OQ-038;
- себестоимость, маржа, staff-комментарии и закрытые контакты не копируются;
- lifecycle соответствует реестру статусов.

## Критерии приёмки Launch MVP

- одна организация создаёт груз и транспорт;
- другая организация находит только active объявления;
- owner редактирует/приостанавливает своё объявление, но не чужое;
- данные каждого поддержанного вида транспорта сохраняются без потери;
- private object остаётся недоступен участникам Exchange;
- публикация и снятие фиксируются в аудите;
- forbidden, validation и limit reached states различаются; moderation states добавляются только если утверждены OQ-039/OQ-040.
- карточка владельца открывает минимальный профиль без выдуманного verified-статуса.
