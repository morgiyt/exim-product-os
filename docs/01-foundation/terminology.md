# Терминология

Одно слово «заявка» нельзя использовать для всех стадий.

| Термин | Определение |
|---|---|
| Обращение | Первичный контакт: сайт, бот, звонок, реклама или исходящий контакт менеджера. |
| Запрос на расчёт | Структурированная потребность клиента: груз, маршрут, сроки и услуги. |
| Расчёт | Внутренняя работа логиста: маршрут, себестоимость, расходы, сроки и условия. |
| Коммерческое предложение | Итоговое предложение клиенту с ценой EXIM. |
| Сделка | Согласование цены, договора и оплаты. |
| Перевозка | Исполняемый заказ после договора. |
| Рейс | Отдельная машина, контейнер, вагон или отправление внутри перевозки. |
| Внутреннее событие | Информация сотрудников, недоступная клиенту. |
| Клиентское событие | Подготовленное менеджером обновление для клиента. |
| Задача | Поручение сотруднику с исполнителем, сроком и статусом. |
