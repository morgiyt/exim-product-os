# Терминология

Одно слово «заявка», «компания» или «роль» нельзя использовать для разных уровней продукта. Термины ниже являются каноническими для версии `0.5.0 — draft`.

## Платформенные термины

| Термин | Определение |
|---|---|
| Платформа | Общий продукт с рабочим названием EXIM Super App: аккаунты, организации, memberships, модули, права, Private OS и Exchange. |
| Оператор платформы | Организация, эксплуатирующая платформенный контур. Будущая структура оператора и её связь с текущим владельцем продукта не утверждены — OQ-047. |
| Tenant / workspace | Изолированная приватная рабочая область организации, использующей Private OS. |
| Первый tenant | `exim.kz` — первая компания с полным Private OS и пилотной конфигурацией. |
| Организация | Юридическое или бизнес-объединение пользователей платформы. Может иметь несколько capabilities и memberships. |
| Компания-контрагент | Клиентская или партнёрская компания внутри Private OS конкретного tenant. Не является синонимом tenant. |
| Membership | Связь пользователя с организацией или tenant с набором ролей и статусов доступа. |
| Роль | Набор прав пользователя внутри конкретного контекста, например менеджер или логист Private OS. |
| Capability | Возможность организации в Exchange. Подтверждено, что capabilities могут совмещаться; точный перечень и модель прав пока являются draft. |
| Модуль | Подключаемая продуктовая область, например Private OS или Exchange. |
| Entitlement | Разрешение организации использовать модуль или конкретную функцию с учётом плана и лимитов. |
| План / тариф | Коммерческий набор entitlements и лимитов. Точные планы пока `TBD`. |

## Продуктовые контуры

| Термин | Определение |
|---|---|
| Private Operating OS | Приватная операционная система логистической компании-tenant. |
| Клиентский портал tenant | Безопасный внешний слой Private OS для клиентов конкретной компании. |
| Биржа грузов и свободного транспорта | Обязательный продуктовый контур; `EXIM Exchange` используется как рабочее название до OQ-047. |
| Участник Exchange | Организация либо иной разрешённый тип участника. Пользователь действует через membership; возможность участия физлица от собственного имени и юридическая модель — OQ-020/OQ-041. |
| Объявление о грузе | Биржевое объявление о потребности найти транспорт или исполнителя. Не равно приватному запросу на расчёт; правила связи — OQ-038. |
| Объявление о транспорте | Биржевое предложение свободного транспорта/вместимости; точный способ публикации — OQ-040. |
| Отклик | Ответ участника на объявление с условиями или намерением связаться. |
| Выбор исполнителя | Решение владельца объявления продолжить взаимодействие с участником. Не является договором с платформой. |
| Стороны сделки | Независимые участники, которые договариваются между собой. EXIM Super App не является стороной сделки между ними; точная юридическая формулировка — OQ-041. |

## Private OS

| Термин | Определение |
|---|---|
| Клиент | Пользователь клиентской компании с доступом в клиентский портал tenant. |
| Лид | Первичный интерес или контакт до закрепления клиента. |
| Запрос на расчёт | Приватная структурированная потребность клиента: маршрут, груз, сроки и вложения. |
| Ставка | Внутренний вариант стоимости и условий от логиста или партнёра. |
| Коммерческое предложение | Итоговое предложение клиенту от конкретной логистической компании-tenant. |
| Договор | Годовой или рамочный договор tenant с клиентом. |
| Заявка к договору | Документ на конкретную перевозку в рамках договора. |
| Перевозка | Исполняемый заказ, созданный после договорного gate. |
| Рейс | Отдельное отправление внутри перевозки. |
| Документ | Файл с правилами видимости и владельцем данных. |
| Задача | Поручение с исполнителем, сроком, статусом и tenant-областью. |
| Платёж | Счёт, оплата и финансовый статус Private OS. |
| Событие tracking | Внутреннее или опубликованное клиенту обновление перевозки/рейса. |

## Workflow

| Термин | Определение |
|---|---|
| Workflow-шаблон | Настраиваемое описание этапов и переходов для типа объекта внутри Private OS. |
| Этап шаблона | Единица процесса с правами, полями и клиентской видимостью. |
| Версия шаблона | Неизменяемый снимок процесса для объектов конкретного tenant. |
| Настраиваемое поле | Дополнительное поле без изменения базовой модели. |
| Экземпляр workflow | Процесс, привязанный к конкретному объекту и tenant. |
| Эскалация | Автоматическое или ручное повышение при просрочке или блокере. |

## Обязательные различия

- `Tenant` ≠ компания-контрагент.
- `Приватный запрос на расчёт` ≠ `объявление о грузе`.
- `Ставка логиста` ≠ `Exchange-отклик`.
- `Роль пользователя` ≠ `тип организации`.
- `Отдельный бизнес-модуль` ≠ `обязательный технический микросервис`.
- `Контейнерный каталог/инфраструктурный marketplace` ≠ `EXIM Exchange грузов и транспорта`.
