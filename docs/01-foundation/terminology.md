# Терминология

Одно слово «заявка» нельзя использовать для всех стадий. Этапы процессов настраиваются через workflow-шаблоны (см. [Configurable Workflow Foundation](./configurable-workflow-foundation)).

| Термин | Определение |
|---|---|
| Клиент | Пользователь клиентской компании с доступом в ЛК. |
| Компания | Клиентская или партнёрская организация. |
| Лид | Первичный интерес или контакт до закрепления клиента. |
| Запрос на расчёт | Структурированная потребность: маршрут, груз, сроки и вложения. |
| Ставка | Вариант цены от логиста или партнёра с полями срока и доступности. |
| Коммерческое предложение | Итоговое предложение клиенту с ценой EXIM. |
| Договор | Годовой или рамочный договор с клиентом. |
| Заявка к договору | Документ на конкретную перевозку в рамках договора. |
| Перевозка | Исполняемый заказ после подписания договора/заявки. |
| Рейс | Отдельное отправление внутри перевозки. |
| Документ | Файл с правилами видимости. |
| Задача | Поручение с исполнителем, сроком и статусом. |
| Платёж | Счёт, оплата и финансовый статус. |
| Событие | Внутреннее или клиентское обновление. |
| Workflow-шаблон | Настраиваемое описание этапов и переходов для типа объекта. |
| Этап шаблона | Единица процесса с правами, полями и клиентской видимостью. |
| Версия шаблона | Неизменяемый снимок процесса для новых и существующих объектов. |
| Настраиваемое поле | Дополнительное поле без изменения кода интерфейса. |
| Экземпляр workflow | Процесс, привязанный к конкретному объекту. |
| Эскалация | Автоматическое или ручное повышение при просрочке / блокере. |
