# Терминология

Одно слово «заявка» нельзя использовать для всех стадий. Для договора отдельно: «заявка к договору».

| Термин | Определение |
|---|---|
| Лид | Первичный интерес или контакт до закрепления клиента и стабильной работы. |
| Обращение | Первичный контакт: сайт, бот, звонок, реклама или исходящий контакт менеджера. |
| Клиентская компания | Организация клиента; у неё один основной менеджер и может быть несколько пользователей. |
| Пользователь клиента | Человек с доступом в клиентский кабинет от имени компании. |
| Основной менеджер | Персональный менеджер клиентской компании. |
| Передача клиента | Временная смена менеджера с обязательной заметкой: ситуация, согласовано, проблемы, следующие действия. |
| Запрос на расчёт | Структурированная потребность: маршрут, груз, сроки, способ погрузки, тип перевозки и вложения. |
| Расчёт | Ответ логиста: цена, комментарий что входит и не входит; хранятся все версии. |
| Коммерческое предложение | Итоговое предложение клиенту с ценой EXIM и включёнными услугами. |
| Сделка | Согласование цены, договора/заявки и условий до исполнения. |
| Годовой договор | Основной договор с клиентом на год; продлевается. |
| Заявка к договору | Отдельный документ на конкретную перевозку в рамках годового договора. |
| Изменение цены | Запись со старой и новой ценой, причиной, автором и датой. |
| Перевозка | Исполняемый заказ после подписания договора/заявки к договору. |
| Рейс | Отдельная машина, контейнер, вагон или отправление внутри перевозки. |
| Внутреннее событие | Информация сотрудников, недоступная клиенту. |
| Клиентское событие | Подготовленное менеджером обновление для клиента. |
| Плановая дата | Дата, которую клиенту сообщает менеджер; история изменений с причиной сохраняется. |
| Задача | Поручение сотруднику с исполнителем, сроком и статусом. |
