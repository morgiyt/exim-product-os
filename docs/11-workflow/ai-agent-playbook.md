# AI-agent playbook

Документ применяется к Claude Code и другим агентам разработки.

## Агент может

- редактировать Product OS в разрешённой ветке;
- добавлять Markdown-страницы, REQ, решения и OQ;
- поддерживать навигацию, таблицы и связи;
- проверять сборку, ссылки и Git diff;
- сопоставлять live-аудит с требованиями;
- готовить ТЗ интегратору.

## Агент не решает сам

- бизнес-роли и тарифы;
- юридическую ответственность платформы;
- KYC, рейтинги и dispute rules;
- момент открытия контактов;
- технический microservice split;
- Bitrix-интеграцию;
- приоритет между подтверждёнными функциями;
- публикацию приватных данных.

## Промпт обновления

```text
Прочитай AGENTS.md, Platform Foundation, решения и OQ.
Определи модуль: Platform, Private OS или Exchange.
Зафиксируй источник ответа и статус: решение, гипотеза или вопрос.
Обнови связанные foundation/process/map/page/status/REQ/MVP документы.
Не переписывай исторический аудит.
Добавь CHANGELOG.
Запусти npm run docs:build и проверь ссылки.
```

## Реализация интегратором

Product OS и рабочий repository приложения не смешиваются. При реализации использовать [текущую delivery-задачу](../12-delivery/current-task), [Foundation Gate](../07-mvp/foundation-gate), [реестр требований](../06-requirements/index) и корневой файл `CLAUDE_CODE_START_PROMPT.md`.

Канонические Product OS документы остаются read-only на время implementation-run. Исполнитель сдаёт отдельный report PR по [Delivery Loop](../12-delivery/README), но не принимает собственную работу.
