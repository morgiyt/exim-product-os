# Cursor playbook

## Cursor может

Создавать Markdown, поддерживать навигацию, добавлять страницы, строить таблицы, проверять ссылки, запускать сборку и вести Git.

## Cursor не решает сам

Роли бизнеса, финансовые правила, юридический процесс, момент создания перевозки, клиентскую видимость, Bitrix и приоритеты MVP.

## Промпт обновления

```text
Прочитай AGENTS.md и связанные документы.
Добавь подтверждённый ответ на OQ-XXX.
Обнови решения, роль, процесс, страницу, открытые вопросы и CHANGELOG.
Не добавляй функций сверх ответа.
После изменения запусти npm run docs:build.
```
