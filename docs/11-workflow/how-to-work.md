# Как работать с Product OS

```text
Вопрос
→ интервью с владельцем процесса
→ запись ответа
→ решение или гипотеза
→ обновление страниц
→ отдельное ТЗ
→ реализация интегратором
→ приёмка
```

ТЗ создаётся только когда известны цель, роль, сценарий, данные, кнопки, статусы, права, ошибки и критерии приёмки.

Не давать ТЗ интегратору, если процесс не подтверждён, роли конфликтуют, неизвестен источник данных или функция относится к отдельному продукту.
