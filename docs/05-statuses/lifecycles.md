# Жизненные циклы

## Запрос

```text
Черновик
→ Отправлен
→ На проверке менеджера
→ Требует уточнения
→ Готов к расчёту
→ Назначен логист
→ На расчёте
→ Расчёт получен
→ Формируется цена
→ Предложение отправлено
→ Согласовано
→ Отказ клиента / Закрыт
```

Просрочка считается по дедлайну и не заменяет бизнес-статус.

## Перевозка

```text
Подготовка
→ Ожидается запуск
→ Назначение транспорта
→ Погрузка
→ В пути
→ Таможенное оформление
→ Доставка
→ Разгрузка
→ Закрывающие документы
→ Завершено
```

Дополнительные состояния: приостановлено, задержка, отменено, проблема, требуется действие клиента.
