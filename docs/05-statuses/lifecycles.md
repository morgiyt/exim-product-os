# Жизненные циклы

## Лид

```text
Новый
→ В работе менеджера
→ Преобразован в клиента / запрос
→ Отклонён / Закрыт
```

## Запрос на расчёт

```text
Черновик
→ Отправлен
→ На проверке менеджера
→ Требует уточнения
→ Готов к расчёту
→ Назначен логист
→ На расчёте
→ Расчёт получен
→ Цена не получена
→ Формируется цена
→ Предложение отправлено
→ Согласовано
→ Отказ клиента / Закрыт
```

Статус «Цена не получена» — технический маркер; бизнес-правило обработки — OQ-022.  
Числовой SLA расчёта не утверждён (OQ-021); просрочка по внутреннему контрольному сроку не утверждает SLA как факт.

## Расчёт

```text
Черновик
→ Отправлен менеджеру
→ Уточнение запрошено
→ Выбран
→ Не выбран / Заменён новой версией
```

Все версии сохраняются. Перезапись без истории запрещена.

## Коммерческое предложение / сделка

```text
Черновик
→ Отправлено клиенту
→ На согласовании
→ Согласовано
→ Требует пересчёта
→ Отказ
→ Закрыто
```

Изменение цены фиксирует: старую цену, новую цену, причину, автора, дату.

## Годовой договор

```text
Черновик
→ На согласовании
→ Подписан
→ Действует
→ Продлён
→ Истёк / Расторгнут
```

## Заявка к договору

```text
Черновик
→ На подписании
→ Подписана
→ Исполняется
→ Закрыта / Отменена
```

## Перевозка

```text
Подготовка
→ Ожидается запуск
→ Назначение транспорта
→ Погрузка
→ В пути
→ Таможенное оформление
→ Доставка
→ Разгрузка
→ Закрывающие документы
→ Завершено
```

Дополнительные состояния: приостановлено, задержка, отменено, проблема, требуется действие клиента.

## Поэтапное закрытие перевозки

```text
Груз доставлен
→ АВР подписан обеими сторонами
→ Оплата получена
→ Документы возвращены
→ Полное закрытие
```

Обязательный полный набор условий закрытия сделки — OQ-025.

## Плановая дата

Каждое изменение сохраняет предыдущую дату, новую дату, причину, автора и момент изменения. Клиенту видна актуальная дата и подготовленные менеджером пояснения.
