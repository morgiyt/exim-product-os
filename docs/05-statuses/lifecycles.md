# Жизненные циклы

## Лид

```text
Новый
→ В работе менеджера
→ Преобразован в клиента / запрос
→ Отклонён / Закрыт
```

## Запрос на расчёт

```text
Черновик
→ Отправлен
→ На проверке менеджера
→ Передан логисту
→ На проверке логиста
→ Возвращён на уточнение
→ На расчёте
→ Ставки получены
→ Ставки не получены
→ Вариант выбран
→ Формируется цена
→ Предложение отправлено
→ Согласовано
→ Отказ клиента / Закрыт
```

Статус «Ставки не получены» — технический маркер; бизнес-правило — OQ-028.  
Числовой SLA расчёта не утверждён (OQ-021).

## Расчёт и варианты ставок

```text
Черновик
→ Поиск у партнёров / на площадках
→ Отправлен менеджеру
→ Возвращён на уточнение
→ Выбран менеджером и клиентом
→ Не выбран / Заменён новой версией
```

Все версии и варианты сохраняются. Перезапись без истории запрещена.

## Коммерческое предложение / сделка

```text
Черновик
→ Отправлено клиенту
→ На согласовании
→ Согласовано
→ Требует пересчёта
→ Отказ
→ Закрыто
```

Изменение цены до забора груза: старая/новая цена, причина, автор, дата, согласование клиента.

## Годовой договор

```text
Черновик
→ На согласовании
→ Подписан
→ Действует
→ Продлён
→ Истёк / Расторгнут
```

## Заявка EXIM ↔ клиент

```text
Черновик
→ На подписании
→ Подписана
→ Исполняется
→ Закрыта / Отменена
```

Подписывается до заявки логиста с партнёром.

## Заявка логиста ↔ партнёр

```text
Черновик
→ Согласование условий
→ На подписании
→ Подписана
→ Исполняется
→ Закрыта / Отменена
```

## Перевозка

```text
Подготовка
→ Ожидается запуск
→ Согласование с партнёром
→ Назначение транспорта / данные водителя
→ Погрузка
→ В пути
→ Таможенное оформление
→ Доставка
→ Разгрузка
→ Закрывающие документы
→ Завершено
```

Точный набор статусов не утверждён — OQ-026.  
Дополнительные состояния: приостановлено, задержка, отменено, проблема, требуется действие клиента.

## Проблема в пути

```text
Зафиксирована
→ В работе у логиста
→ Решена
→ Эскалация
```

## Поэтапное закрытие перевозки

```text
Груз доставлен
→ АВР подписан обеими сторонами
→ Оплата получена
→ Документы возвращены
→ Полное закрытие
```

Обязательный полный набор условий закрытия сделки — OQ-025.

## Плановая дата

Каждое изменение сохраняет предыдущую дату, новую дату, причину, автора и момент изменения. Клиенту видна актуальная дата и подготовленные менеджером пояснения.

## Изменение ставки / цены

| Период | Правило |
|---|---|
| До забора груза | Может измениться при изменении данных по грузу; нужны причина и согласование клиента |
| После начала перевозки | Ставка обычно не меняется |
