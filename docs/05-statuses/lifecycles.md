# Жизненные циклы

## Лид

```text
Новый
→ В работе менеджера
→ Преобразован в клиента / запрос
→ Отклонён / Закрыт
```

## Запрос на расчёт

```text
Черновик
→ Запрос от отдела продаж
→ Отправлен на просчёт
→ На проверке логиста
→ Возвращён на уточнение
→ На расчёте
→ Ставка просчитана
→ Запрос на перерасчёт
→ Повторный расчёт
→ Ставки не получены
→ Вариант выбран
→ Предложение отправлено
→ Согласовано
→ Закрыт (причина обязательна)
→ Отказ клиента
```

Если ставки нет: поиск продолжается → возврат менеджеру или закрытие с причиной (D-063).  
Единого SLA нет (D-020); ожидаемый срок — H-003; перенос срока — новая дата + причина (D-055).

## Расчёт и варианты ставок

```text
Черновик
→ Поиск у партнёров / на площадках
→ Ставка получена
→ Отправлен менеджеру
→ Возвращён на уточнение
→ Выбран менеджером и клиентом
→ Не выбран / Заменён перерасчётом
```

Для каждой ставки: дата получения, срок действия, цена, доступность транспорта, комментарий, история перерасчётов (D-056).  
Наличие ставки ≠ гарантия машины до подтверждения клиентом (D-057).

## Коммерческое предложение / сделка

```text
Черновик
→ Отправлено клиенту
→ На согласовании
→ Согласовано
→ Клиент подписал договор/заявку
→ Требует пересчёта
→ Сделка провалена
→ Анализ причины
→ Закрыто
```

## Договор / заявка

```text
Черновик
→ На подписании
→ Клиент подписал
→ Рассмотрение договора агентом
→ Договор рассмотрен
→ Исполняется
→ Закрыта / Отменена
```

## Перевозка — операционные этапы (D-058)

```text
Запрос от отдела продаж
→ Отправлен на просчёт
→ Ставка просчитана
→ Запрос на перерасчёт (при необходимости)
→ Повторный расчёт (при необходимости)
→ Клиент подписал договор/заявку
→ Рассмотрение договора агентом
→ Договор рассмотрен
→ Связь с заводом
→ Ожидание забора
→ Погрузка
→ Груз едет до границы
→ Груз на границе
→ Груз едет до СВХ
→ Груз прибыл на СВХ
→ Ожидание оплаты
→ Завершено
```

Клиенту публикует подготовленные формулировки менеджер (D-012, D-013).

## Tracking (D-060, D-061)

```text
Логист получает информацию (звонок / WhatsApp водителю)
→ Фиксирует: источник, дата, автор, текстовая локация
→ Менеджер готовит клиентскую формулировку
→ Публикует клиенту
```

Контакты водителя клиенту не показываются (D-062).

## Проблема в пути

```text
Зафиксирована
→ В работе у логиста
→ Решена
→ Эскалация
```

## Поэтапное закрытие перевозки

```text
Груз доставлен
→ АВР подписан обеими сторонами
→ Оплата получена
→ Документы возвращены
→ Полное закрытие
```

Полный набор условий — OQ-025.

## Изменение ставки / цены

| Период | Правило |
|---|---|
| До забора груза | Может измениться при изменении данных по грузу; нужны причина и согласование клиента |
| После начала перевозки | Ставка обычно не меняется |

## Перенос ожидаемого срока расчёта

```text
Указан ожидаемый срок (H-003)
→ Срок перенесён (новая дата + причина обязательны)
→ Ставка получена / возврат / закрытие
```
