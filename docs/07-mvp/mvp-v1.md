# MVP v1

## Цель

Провести одну реальную перевозку от запроса до закрытия и дать клиенту достоверный ручной tracking.

## Сквозной сценарий

```text
Менеджер создаёт клиента
→ создаёт запрос
→ назначает логиста
→ получает расчёт
→ добавляет маржу
→ фиксирует договор
→ создаёт перевозку
→ создаёт рейсы
→ публикует события
→ клиент отслеживает
→ перевозка закрывается
```

## Обязательно

- авторизация и роли;
- клиентская компания и основной менеджер;
- запрос, дедлайн и расчёт;
- разделение себестоимости и итоговой цены;
- перевозка и рейсы;
- внутреннее и клиентское событие;
- клиентская карточка перевозки;
- документы;
- чат клиент — менеджер;
- задача логиста и просрочка;
- аудит критических действий.

## Не входит

GPS, WhatsApp, Telegram, email-автоматизация, встроенная оплата, ЭЦП, полная замена Bitrix, marketplace, каталог инфраструктуры и кабинет сторонней логистической компании.
