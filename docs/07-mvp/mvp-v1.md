# MVP v1

## Цель

Провести одну реальную перевозку от запроса до закрытия на **настраиваемых workflow-шаблонах** и дать клиенту достоверный tracking без внутренних данных EXIM.

## Сквозной сценарий

```text
Менеджер создаёт клиента и запрос (workflow: запрос v1)
→ логист просчитывает ставки
→ менеджер и клиент выбирают вариант
→ договор / заявка (workflow: договор v1)
→ перевозка создаётся (workflow: перевозка v1 — референс D-058)
→ рейсы (workflow: рейс v1)
→ менеджер публикует клиентские этапы
→ бухгалтер ведёт платёж (workflow: финансы v1 — базовый D-074)
→ закрытие
```

## Обязательно

- фиксированные сущности (D-065);
- workflow-движок: шаблон, версия, этап, экземпляр, история;
- референсные шаблоны v1: запрос, перевозка, рейс, финансы;
- настраиваемые поля (минимум: текст, число, дата, файл, список);
- права ролей на этап (D-071);
- клиентская видимость этапов (D-072);
- аудит изменений (D-069);
- задачи, дедлайны, in-app уведомления (D-073);
- упрощённый редактор шаблонов для администратора;
- разделение staff / client слоёв;
- сквозной сценарий из интервью продаж и логистики.

## Не входит

- полный BPMN-редактор;
- автоматическая миграция объектов между версиями шаблона;
- внешние уведомления (email, WhatsApp, Telegram);
- GPS, встроенная оплата, ЭЦП;
- полная замена Bitrix.

## Гипотезы MVP

- H-001 — приглашение клиента после расчёта;
- H-003 — индивидуальный ожидаемый срок ставки;
- минимальный набор шаблонов — OQ-029.
