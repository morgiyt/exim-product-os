# Roadmap

## Этап 0 — Product Foundation

Интервью, термины, роли, процесс, страницы, статусы, wireframe.  
Configurable Workflow Foundation (2026-07-27).

## Этап 1 — Рабочая демонстрация (MVP)

- workflow-движок с версиями шаблонов;
- референсные шаблоны: запрос, перевозка, рейс, финансы;
- настраиваемые поля и права на этап;
- один сквозной сценарий;
- ручной tracking;
- dashboard руководителей.

## Этап 2 — Операционная работа

- расширенный редактор workflow;
- эскалации и напоминания;
- шаблоны договора и заявки;
- несколько пользователей клиента;
- полный контур оплаты;
- отчёты руководителей.

## Этап 3 — Интеграции

- Bitrix, «Онлайн Контракт»;
- внешние уведомления;
- автоматизация tracking-источников;
- миграция объектов между версиями шаблонов (OQ-031).

## Этап 4 — Масштабирование

- несколько логистических компаний;
- изоляция данных;
- marketplace-процессы;
- платформенная модель workflow.
