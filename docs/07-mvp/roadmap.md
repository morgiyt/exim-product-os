# Roadmap EXIM Super App

## Этап 0 — Формализация платформы

Статус: текущий Product OS `0.5.0 — draft`.

- multi-tenant направление;
- два продуктовых контура;
- exim.kz как первый tenant;
- tenant/data boundaries;
- Exchange domain и lifecycle верхнего уровня;
- REQ-001…REQ-010;
- новый Release split;
- открытые коммерческие, юридические и технические вопросы.

## Этап 1 — Foundation Gate (рекомендуемый следующий пакет)

Текущий крупный пакет интегратору:

- серверные роли и tenant isolation;
- единые данные, поиск и стабильная навигация;
- mobile и error states;
- request → rates → offer → contract gate → shipment → trip → tracking;
- auth callback;
- проверка минимум семью accounts по матрице REQ-004, двумя TenantWorkspaces и двумя client companies внутри workspace A.

Выход: надёжный Private OS pilot `exim.kz` и безопасная база для Exchange.

## Этап 2 — Exchange MVP и первый публичный запуск

- организации и совмещаемые capabilities;
- объявления грузов и транспорта;
- основные виды перевозок;
- поиск, фильтры и карточки;
- утверждённая после OQ-040 механика взаимодействия участников;
- правила контактов после OQ-043;
- бесплатный и платный доступ;
- профиль и trust/safety только в объёме, утверждённом OQ-039…OQ-041;
- юридические тексты нейтральной платформы;
- launch acceptance двумя независимыми организациями.

Выход: **Public Launch MVP** = работающий Exchange + Private OS `exim.kz`.

До решения OQ-037 рабочий вариант активации paid entitlement не утверждён. Для Launch требуется выбрать либо ручную выдачу после внешней оплаты, либо billing provider; интегратор не выбирает этот путь самостоятельно.

## Этап 3 — Подключение других организаций

- self-service или управляемый onboarding tenant по принятой модели;
- расширение Private OS для других логистических компаний;
- tenant templates и настройки;
- расширенные планы и entitlements;
- операционные dashboards;
- безопасный перенос/импорт данных.

Точный момент полного Private OS для других компаний — OQ-046.

## Этап 4 — Автоматизация и интеграции

- внешние уведомления;
- tracking-источники и GPS по отдельному решению;
- Bitrix и «Онлайн Контракт» по отдельному решению;
- billing provider;
- расширенный workflow editor;
- миграция workflow-версий;
- ranking, доверие, рейтинги и dispute tooling после решений;
- расширение географии.

## Не смешивать с roadmap

Каталог терминалов, СВХ, тупиков, продажа контейнеров и инфраструктурный marketplace относятся к отдельному продукту. Наличие их экранов в live-приложении не означает включение в этот roadmap.
