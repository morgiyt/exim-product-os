# Права и видимость

|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| Итоговая цена и включённые услуги | Да | Да | Да | Да | Да | Да | Да |
| Себестоимость / цена логиста | Нет | Да | Да | Да | Нет* | Нет | Да |
| Маржа | Нет | Да | Нет | Да | Нет | Нет | Да |
| Перевозчик, водитель, телефон | Нет | Да | Да | Да | Нет | Нет | Да |
| Прямые контакты подрядчиков | Нет | Да | Да | Да | Нет | Нет | Да |
| Внутренние события и задачи | Нет | Да | Да | Да | Нет | По задаче | Да |
| Клиентские статусы и причины задержек | Да | Да | Да | Да | Нет | Нет | Да |
| Годовой договор / заявка к договору | Да* | Да | Да | Да | Да | Да | Да |
| Оплата и счета | Да* | Да | Нет | Да | Да | Нет | Да |

\* уточняется в MVP и по согласованию ролей; клиентский слой никогда не содержит себестоимость, маржу и прямые контакты исполнителей.

## Правила

1. Клиентский API не возвращает внутренние поля, даже если UI их скрывает.
2. Клиент общается только со своим менеджером (или временно переданным).
3. Публичные статусы и причины задержек публикует только менеджер.
4. Итоговую цену клиенту показывает менеджер через коммерческое предложение / сделку.
5. Низкая маржа требует согласования руководителя продаж.
6. Временная передача клиента без заметки передачи запрещена.
7. Плановую дату клиенту сообщает только менеджер; история изменений обязательна.

## Роли создания ключевых объектов

| Объект | Создаёт |
|---|---|
| Клиентская компания | Менеджер |
| Пользователь клиента | Менеджер / админ |
| Запрос на расчёт | Менеджер или клиент |
| Расчёт | Логист |
| Коммерческое предложение | Менеджер |
| Годовой договор / заявка к договору | Менеджер (+ юрист) |
| Перевозка | Менеджер вручную после подписания |
| Рейс | Логист |
| Оплата / финансовый статус | Бухгалтер |
| Публикация клиентского статуса | Менеджер |
