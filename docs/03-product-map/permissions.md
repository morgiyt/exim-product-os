|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|

| Себестоимость / ставки | Нет | Да | Да | Да | Нет | Нет | Да |
| Маржа | Нет | Да | Нет | Да | Нет | Нет | Да |

## Права на этап (D-071)

Для каждого `WorkflowStage` задаются права ролей:

| Роль | Типичные права |
|---|---|
| Менеджер | просмотр, переход, публикация клиенту |
| Логист | просмотр, переход, внутренние поля |
| Бухгалтер | просмотр, переход финансовых этапов |
| Юрист | просмотр, переход договорных этапов |
| Руководитель | просмотр, эскалации, отчёты |
| Администратор | полный доступ, редактирование шаблонов |

## Клиентский слой этапа (D-072)

| Настройка | Правило |
|---|---|
| Показывать этап | Если выключено — этап invisible для клиента |
| Клиентское название | Публикуемая формулировка |
| Клиентское описание | Пояснение в ЛК |
| Комментарий менеджера | Если обязателен — без него публикация блокируется |

## Правила

1. Клиентский API не возвращает staff-only этапы, поля и контакты.
2. Переход этапа проверяет права роли и обязательные поля/файлы/комментарий.
3. Публикация клиенту — только через этапы с клиентской видимостью.
4. Изменение шаблона — только администратор; аудит обязателен (D-069).
5. Низкая маржа — согласование руководителя продаж (D-028).
6. Временная передача клиента — обязательная заметка (D-021).

## Роли создания объектов

| Объект | Создаёт |
|---|---|
| Компания / клиент | Менеджер |
| Запрос на расчёт | Менеджер или клиент |
| Ставка | Логист |
| Перевозка | Менеджер |
| Workflow-шаблон | Администратор |
| Платёж | Бухгалтер |

## Универсальные механизмы (D-073)

Задачи, дедлайны, уведомления, напоминания и эскалации наследуют права этапа, на котором созданы.
