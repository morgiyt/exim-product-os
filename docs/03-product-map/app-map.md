# Карта приложения

## Клиент

```text
Главная
├── Мой менеджер
├── Активные перевозки
├── Ожидают моего действия
└── Последние события

Запросы
├── Новый запрос
├── Черновики
├── На расчёте
├── Предложения
└── Архив

Перевозки
├── Активные
├── Завершённые
└── Карточка перевозки
    ├── Обзор
    ├── Рейсы
    ├── Tracking
    ├── Документы
    └── Чат

Компания
├── Пользователи компании
└── Договоры / заявки к договору

Уведомления
Профиль
```

## Менеджер

```text
Главная
├── Новые лиды / обращения
├── Запросы без расчёта
├── Расчёты без ответа логиста
├── Перевозки без обновления
├── Задержки
└── Непрочитанные сообщения

Клиенты
├── Карточка клиента
└── Передача клиента (заметка обязательна)

Запросы на расчёт
Коммерческие предложения
Сделки
Договоры
├── Годовые договоры
└── Заявки к договору
Перевозки
├── Создание перевозки
├── Изменение плановой даты
└── История изменений цены
Задачи
Чаты
Уведомления
```

## Логист

```text
Очередь расчётов
├── Проверка данных
└── Возврат на уточнение

Мои расчёты
├── Поиск ставок (партнёры, FAFA, ATI.SU, Della)
├── Варианты ставок
└── Комментарий: входит / не входит

Согласование с партнёром
├── Условия перевозки и оплаты
└── Заявка логиста ↔ партнёр

Перевозки в работе
├── Данные водителя
├── Проблемы и решения
└── Плановые даты от перевозчика

Рейсы
Документы от завода
Внутренние события
Задачи
Уведомления
```

## Руководитель логистики

```text
Dashboard
├── Просчёты в работе
├── Сроки расчётов
├── Перевозки в работе
├── Проблемы и их решение
├── Работа каждого логиста
├── Запросы на уточнении
└── Случаи без ставки от партнёров

Логисты и нагрузка
Перевозки и риски
```

## Руководитель продаж

```text
Dashboard
├── Новые лиды
├── Заявки без расчёта
├── Просроченные расчёты
├── Предложения без ответа
├── Активные перевозки
├── Задержки
├── Договоры
├── Неоплаченные счета
├── Показатели менеджеров
├── Причины отказов
├── Изменения цен
└── Перевозки без свежего обновления

Согласование низкой маржи
Клиенты и назначения
```

## Бухгалтер

```text
Счета
Оплаты
Неоплаченные перевозки
Финансовые статусы
Документы оплаты
```

## Администратор

```text
Workflow-шаблоны
├── Список шаблонов по типу объекта
├── Версии шаблонов
├── Редактор этапов
│   ├── Названия, порядок, цвет
│   ├── Роли и права
│   ├── Клиентская видимость
│   ├── Обязательные поля / комментарий / файл
│   ├── Переходы
│   └── Уведомления и сроки
├── Настраиваемые поля
├── Базовый финансовый шаблон
├── Правила эскалаций
└── Аудит изменений

Пользователи
Роли и права
Клиентские компании
Назначения менеджеров
Справочники
Журнал аудита
Настройки
```
