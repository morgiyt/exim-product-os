# Карта EXIM Super App

Карта показывает целевую информационную архитектуру. Раздел Private OS опирается на подтверждённый процесс `exim.kz`; Exchange-страницы ниже являются рабочим draft до закрытия OQ-039…OQ-043.

## Общий shell платформы

```text
Публичная зона
├── Вход
├── Регистрация
├── Подтверждение email
├── Восстановление доступа
└── Условия и политика данных

После входа
├── Выбор организации / workspace
├── Главная платформы
├── Доступные модули
├── Уведомления
└── Профиль аккаунта
```

## Граница отдельного продукта

Терминалы, СВХ, железнодорожные тупики, продажа контейнеров и инфраструктурный marketplace не входят в эту карту. Существующий контейнерный экран live-приложения не является EXIM Exchange.
