# Карта приложения

## Клиент

```text
Главная
├── Мой менеджер
├── Активные перевозки
├── Ожидают моего действия
└── Последние события

Запросы
├── Новый запрос
├── Черновики
├── На расчёте
├── Предложения
└── Архив

Перевозки
├── Активные
├── Завершённые
└── Карточка перевозки
    ├── Обзор
    ├── Рейсы
    ├── Tracking
    ├── Документы
    └── Чат

Компания
├── Пользователи компании
└── Договоры / заявки к договору

Уведомления
Профиль
```

## Менеджер

```text
Главная
├── Новые лиды / обращения
├── Запросы без расчёта
├── Расчёты без ответа логиста
├── Перевозки без обновления
├── Задержки
└── Непрочитанные сообщения

Клиенты
├── Карточка клиента
└── Передача клиента (заметка обязательна)

Запросы на расчёт
Коммерческие предложения
Сделки
Договоры
├── Годовые договоры
└── Заявки к договору
Перевозки
├── Создание перевозки
├── Изменение плановой даты
└── История изменений цены
Задачи
Чаты
Уведомления
```

## Логист

```text
Очередь расчётов
Мои расчёты
├── Версии расчётов
└── Комментарий: входит / не входит
Перевозки в работе
Рейсы
Внутренние события
Плановые даты от перевозчика
Документы
Задачи
Уведомления
```

## Руководитель продаж

```text
Dashboard
├── Новые лиды
├── Заявки без расчёта
├── Просроченные расчёты
├── Предложения без ответа
├── Активные перевозки
├── Задержки
├── Договоры
├── Неоплаченные счета
├── Показатели менеджеров
├── Причины отказов
├── Изменения цен
└── Перевозки без свежего обновления

Согласование низкой маржи
Клиенты и назначения
```
