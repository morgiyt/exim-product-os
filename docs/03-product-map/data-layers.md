# Два слоя информации

## Внутренний слой EXIM

- себестоимость и цена логиста;
- маржа и прибыль;
- версии расчётов;
- изменения цен с причинами;
- перевозчики и внутренние контакты;
- водитель и телефон водителя;
- реальные причины задержек;
- внутренние задачи;
- служебные сообщения;
- заметки передачи клиента;
- согласование низкой маржи.

## Клиентский слой

- итоговая стоимость;
- включённые услуги;
- согласованный маршрут;
- плановые сроки (актуальная дата);
- публичные статусы;
- подготовленные менеджером причины задержек;
- клиентские документы;
- сообщения менеджера;
- статусы оплаты в клиентской формулировке.

## Клиент никогда не видит

- перевозчика;
- водителя;
- телефон водителя;
- прямые контакты исполнителей;
- себестоимость;
- маржу.

## Модель события

| Поле | Пример |
|---|---|
| Внутренний тип | DRIVER_UNREACHABLE |
| Внутреннее описание | Водитель не выходит на связь |
| Клиентская формулировка | Время отправления корректируется |
| Автор факта | Логист |
| Публикующий | Менеджер |
| Статус | Ожидает публикации |

Клиентский API не должен возвращать внутренние поля даже если интерфейс их визуально скрывает.

Подробная матрица ролей: [Права и видимость](./permissions).
