# Области и слои данных

## 1. Platform identity

- аккаунт;
- подтверждение контактов;
- организации и memberships;
- доступные модули и entitlements;
- платформенный аудит.

Этот слой не выдаёт пользователю доступ ко всем данным организаций.

## 2. Tenant-private workspace

- себестоимость и ставки;
- маржа и прибыль;
- клиенты и контрагенты;
- перевозчики, водитель и внутренние контакты;
- внутренние задачи, сообщения и причины задержек;
- договоры, документы и финансы;
- workflow и аудит tenant.

Все объекты имеют tenant/workspace scope.

## 3. Клиентский слой tenant

- итоговая стоимость и включённые услуги;
- согласованный маршрут;
- актуальные плановые сроки;
- опубликованные статусы и причины задержек;
- клиентские документы;
- сообщения персонального менеджера;
- разрешённые финансовые статусы.

Клиентский API не возвращает staff-only поля, даже если интерфейс их скрывает.

## 4. Exchange-слой

Ниже — рабочая logical boundary. Конкретный состав профиля, отклика, контактов и moderation зависит от OQ-039…OQ-043.

- разрешённые правилами видимости поля груза или транспорта;
- публичные/ограниченные данные профиля организации;
- отклики и предложения только их участникам;
- контакты только после разрешённого события;
- moderation metadata только уполномоченным ролям.

## Возможная связь с Private OS — предлагаемый safe default

Сам механизм не утверждён. До закрытия OQ-038 схема ниже является рекомендацией безопасности, а не принятой продуктовой механикой:

```text
Приватный QuoteRequest
→ явное действие уполномоченного пользователя
→ предпросмотр разрешённых публичных полей
→ подтверждение публикации
→ отдельный CargoListing
→ независимый lifecycle и аудит
```

До решения OQ-038 запрещено реализовывать неописанную интеграцию. Если связь будет утверждена, обязательные guardrails:

- автоматически публиковать все запросы;
- копировать себестоимость, маржу, внутренние комментарии и контакты;
- использовать один объект одновременно как приватную заявку и публичное объявление;
- разрешать Exchange-поиску обход tenant isolation.

Инициатор, согласие, режим создания/копирования и точные public fields — OQ-038.
