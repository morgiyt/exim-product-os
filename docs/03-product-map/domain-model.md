# Доменная модель

```text
Клиентская компания
├── Контактные лица
├── Основной менеджер
├── Обращения
├── Запросы на расчёт
├── Коммерческие предложения
└── Перевозки
    ├── Ответственные сотрудники
    ├── Рейсы
    │   ├── Транспорт
    │   ├── События
    │   └── Документы
    ├── Клиентские события
    ├── Внутренние события
    ├── Документы
    ├── Финансовые статусы
    ├── Задачи
    └── Чат
```

| Сущность | Назначение |
|---|---|
| Organization | Компания клиента или EXIM |
| User | Человек с доступом |
| ManagerAssignment | Назначение менеджера клиенту |
| Lead | Первичное обращение |
| QuoteRequest | Запрос на расчёт |
| Calculation | Внутренний расчёт логиста |
| CommercialOffer | Предложение клиенту |
| Contract | Договор и статусы |
| Shipment | Общая перевозка |
| Trip | Отдельный рейс |
| Event | Внутреннее или клиентское событие |
| Document | Файл и видимость |
| Task | Внутренняя задача |
| Conversation | Чат клиента и менеджера |
| AuditLog | История критических действий |

## Перевозка и рейсы

Одна перевозка может содержать десять машин. Клиент видит одну общую карточку и раскрывающийся список рейсов.
