# Доменная модель

```text
Клиентская компания
├── Пользователи клиента (несколько)
├── Основной менеджер
├── Временные передачи менеджера + заметки
├── Лиды / обращения
├── Запросы на расчёт
│   ├── Проверка данных логистом
│   └── Версии расчётов
│       └── Варианты ставок (партнёр / площадка)
├── Коммерческие предложения
├── Сделки
├── Годовой договор
│   └── Заявки к договору (EXIM ↔ клиент)
└── Перевозки
    ├── Ответственный логист (автор выбранного расчёта)
    ├── Заявка логиста ↔ партнёр
    ├── Данные водителя (внутренний слой)
    ├── Проблемы и решения
    ├── История изменений цены
    ├── История плановых дат
    ├── Рейсы
    │   ├── Транспорт / перевозчик (внутренний слой)
    │   ├── События
    │   └── Документы
    ├── Документы от завода
    ├── Клиентские события
    ├── Внутренние события
    ├── Финансовые статусы / оплата
    ├── Этапы закрытия
    ├── Задачи
    └── Чат
```

| Сущность | Назначение |
|---|---|
| Organization | Компания клиента, EXIM или партнёр |
| User | Человек с доступом |
| ManagerAssignment | Основной менеджер клиенту |
| ClientHandoverNote | Обязательная заметка временной передачи клиента |
| Lead | Лид / первичное обращение |
| QuoteRequest | Запрос на расчёт |
| Calculation | Версия расчёта логиста |
| RateQuote | Вариант ставки от партнёра или площадки (FAFA, ATI.SU, Della и др.) |
| CommercialOffer | Предложение клиенту |
| Deal | Сделка |
| AnnualContract | Годовой договор |
| ContractApplication | Заявка EXIM ↔ клиент на перевозку |
| PartnerApplication | Заявка логиста ↔ партнёр |
| PriceChange | Изменение цены: старая/новая, причина, автор, дата, согласование клиента |
| PlannedDateChange | История плановых дат с причиной |
| Shipment | Перевозка |
| Trip | Рейс |
| DriverInfo | Данные водителя (внутренний слой) |
| TransportIssue | Проблема в пути и её решение |
| FactoryDocument | Документ от завода: инвойс, упаковочный лист, сертификат, разрешение |
| Event | Внутреннее или клиентское событие |
| Document | Файл и видимость |
| Payment | Оплата / счёт (ведёт бухгалтер) |
| Task | Внутренняя задача |
| Conversation | Чат клиента и менеджера |
| AuditLog | История критических действий |

## Разделение сущностей

Не смешивать: лид ≠ запрос на расчёт ≠ вариант ставки ≠ коммерческое предложение ≠ сделка ≠ годовой договор ≠ заявка к договору ≠ заявка с партнёром ≠ перевозка ≠ рейс.

## Порядок заявок

1. Заявка EXIM с клиентом (`ContractApplication`).
2. Заявка логиста с партнёром (`PartnerApplication`).

## Перевозка и рейсы

Рабочая модель: одна перевозка может содержать несколько рейсов. Точные статусы перевозки — OQ-026. Способ tracking — OQ-027.

## Изменение цены

- до забора груза: при изменении данных по грузу, с причиной и согласованием клиента;
- после начала перевозки: ставка обычно не меняется.
