# Доменная модель

```text
Клиентская компания
├── Пользователи клиента (несколько)
├── Основной менеджер
├── Временные передачи менеджера + заметки
├── Лиды / обращения
├── Запросы на расчёт
│   ├── Проверка данных логистом
│   ├── Ожидаемый срок ставки (H-003)
│   ├── История переносов срока
│   └── Версии расчётов
│       └── Варианты ставок
│           ├── дата получения, срок действия
│           ├── цена, доступность транспорта
│           ├── комментарий
│           └── история перерасчётов
├── Коммерческие предложения
├── Сделки
│   └── Анализ причины провала
├── Годовой договор
│   └── Заявки к договору (EXIM ↔ клиент)
└── Перевозки
    ├── Операционные этапы (D-058)
    ├── Ответственный логист
    ├── Заявка логиста ↔ партнёр
    ├── Данные водителя (внутренний слой, D-062)
    ├── Tracking-обновления (источник, дата, автор, локация)
    ├── Проблемы и решения
    ├── История изменений цены
    ├── История плановых дат
    ├── Рейсы
    ├── Документы от завода
    ├── Клиентские события
    ├── Внутренние события
    ├── Финансовые статусы / оплата
    ├── Этапы закрытия
    └── Чат
```

| Сущность | Назначение |
|---|---|
| Organization | Компания клиента, EXIM или партнёр |
| User | Человек с доступом |
| ManagerAssignment | Основной менеджер клиенту |
| ClientHandoverNote | Обязательная заметка временной передачи клиента |
| Lead | Лид / первичное обращение |
| QuoteRequest | Запрос на расчёт |
| ExpectedRateDeadline | Ожидаемый срок ставки и время обновления (H-003) |
| DeadlineChange | Перенос срока: новая дата + причина |
| Calculation | Версия расчёта логиста |
| RateQuote | Ставка: дата получения, срок действия, цена, доступность, комментарий |
| RateRecalculation | Запись перерасчёта в истории ставки |
| CommercialOffer | Предложение клиенту |
| Deal | Сделка |
| DealFailureAnalysis | Анализ причины провала сделки |
| AnnualContract | Годовой договор |
| ContractApplication | Заявка EXIM ↔ клиент |
| PartnerApplication | Заявка логиста ↔ партнёр |
| PriceChange | Изменение цены с согласованием клиента |
| PlannedDateChange | История плановых дат с причиной |
| Shipment | Перевозка с операционными этапами |
| Trip | Рейс |
| DriverInfo | Данные водителя (не для клиента) |
| TrackingUpdate | Обновление: источник, дата, автор, текстовая локация |
| TransportIssue | Проблема в пути и решение |
| FactoryDocument | Инвойс, упаковочный лист, сертификат, разрешение |
| Event | Внутреннее или клиентское событие |
| Document | Файл и видимость |
| Payment | Оплата / счёт |
| Conversation | Чат клиента и менеджера |
| AuditLog | История критических действий |

## Разделение сущностей

Не смешивать: лид ≠ запрос ≠ ставка ≠ предложение ≠ сделка ≠ договор ≠ заявка ≠ перевозка ≠ tracking-обновление ≠ рейс.

## SLA расчёта

Единого фиксированного SLA нет (D-020). Индивидуальный ожидаемый срок — H-003.

## Ставка и транспорт

Наличие `RateQuote` не гарантирует машину до подтверждения варианта клиентом (D-057).

## Tracking

Источники: звонок, WhatsApp водителю (D-060). Поля `TrackingUpdate`: источник, дата, автор, текстовая локация (D-061).

## Отсутствие ставки

Поиск продолжается → возврат менеджеру или закрытие с причиной; менеджер может закрыть, если клиент решил сам (D-063).

## Изменение цены

- до забора: при изменении данных по грузу, с согласованием клиента;
- после начала перевозки: ставка обычно не меняется.
