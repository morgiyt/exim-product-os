# Доменная модель

```text
Клиентская компания
├── Пользователи клиента (несколько)
├── Основной менеджер
├── Временные передачи менеджера + заметки
├── Лиды / обращения
├── Запросы на расчёт
│   └── Версии расчётов логиста
├── Коммерческие предложения
├── Сделки
├── Годовой договор
│   └── Заявки к договору
└── Перевозки
    ├── Ответственный логист (автор выбранного расчёта)
    ├── История изменений цены
    ├── История плановых дат
    ├── Рейсы
    │   ├── Транспорт / перевозчик (внутренний слой)
    │   ├── События
    │   └── Документы
    ├── Клиентские события
    ├── Внутренние события
    ├── Документы
    ├── Финансовые статусы / оплата
    ├── Этапы закрытия
    ├── Задачи
    └── Чат
```

| Сущность | Назначение |
|---|---|
| Organization | Компания клиента или EXIM |
| User | Человек с доступом |
| ManagerAssignment | Основной менеджер клиенту |
| ClientHandoverNote | Обязательная заметка временной передачи клиента |
| Lead | Лид / первичное обращение |
| QuoteRequest | Запрос на расчёт |
| Calculation | Версия расчёта логиста (цена + комментарий вхождения услуг) |
| CommercialOffer | Предложение клиенту |
| Deal | Сделка |
| AnnualContract | Годовой договор |
| ContractApplication | Заявка к договору на перевозку |
| PriceChange | Изменение цены: старая/новая, причина, автор, дата |
| PlannedDateChange | История плановых дат с причиной |
| Shipment | Перевозка |
| Trip | Рейс |
| Event | Внутреннее или клиентское событие |
| Document | Файл и видимость |
| Payment | Оплата / счёт (ведёт бухгалтер) |
| Task | Внутренняя задача |
| Conversation | Чат клиента и менеджера |
| AuditLog | История критических действий |

## Разделение сущностей

Не смешивать: лид ≠ запрос на расчёт ≠ коммерческое предложение ≠ сделка ≠ годовой договор ≠ заявка к договору ≠ перевозка ≠ рейс.

## Перевозка и рейсы

Рабочая модель: одна перевозка может содержать несколько рейсов; клиент видит одну карточку и список рейсов. Альтернатива «отдельные перевозки на каждое отправление» — открытый вопрос OQ-024.
