# Кабинет клиента

## CL-001 — Главная

Блоки: персональный менеджер, активные перевозки, последние события, требуемые действия, документы, кнопка нового запроса.

## CL-002 — Новый запрос

Обязательные поля: откуда, куда, вес, дата готовности, штабелирование, размеры, способ погрузки, тип перевозки, фотографии.

Дополнительно по ситуации: упаковка, код ТН ВЭД, объём, места, адреса, таможня, склад, комментарий, телефон.

После отправки запрос поступает менеджеру и получает номер. Если отправитель новый, менеджер связывается и при успешной работе закрепляет клиента за собой.

Момент приглашения в приложение — гипотеза H-001 / OQ-023: не утверждать автоматический аккаунт для случайного лида.

## CL-004 — Карточка перевозки

Верхний блок: номер, статус, маршрут, прогресс, плановая дата, последнее обновление и менеджер.

Вкладки:

- обзор;
- рейсы;
- tracking;
- документы;
- чат.

Кнопки: написать менеджеру, открыть рейс, скачать или загрузить документ, сообщить о проблеме.

Клиент видит только итоговую цену, включённые услуги и подготовленные менеджером статусы / причины задержек.

Клиент не видит себестоимость, маржу, перевозчика, водителя, телефон водителя, прямые контакты, внутренние события, задачи и служебные файлы.
