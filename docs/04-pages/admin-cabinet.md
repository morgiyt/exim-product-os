# Кабинет администратора

Страница относится к **tenant admin** Private OS. Platform admin и moderation описываются отдельно. Foundation Gate требует только read-only просмотр предустановленных шаблонов; полноценный редактор ниже относится к последующему этапу.

## AD-001 — Workflow-шаблоны

### Цель

В Gate — безопасный read-only просмотр активных шаблонов и версий. Ниже также сохранён draft будущего управления процессами без изменения кода приложения.

### Роли с доступом

- Foundation Gate: tenant admin — read-only просмотр своего tenant;
- будущий editor: точная роль создания/редактирования — OQ-030/OQ-044;
- руководительские предложения изменений — гипотеза до OQ-030.

### Блоки

- список шаблонов по типу объекта (запрос, перевозка, рейс, договор, заявка, платёж);
- версии шаблона (активная / архивные);
- редактор этапов;
- настраиваемые поля;
- граф переходов;
- правила уведомлений и эскалаций;
- журнал изменений шаблонов.

### Редактор этапа (D-067)

| Поле | Настройка |
|---|---|
| Внутреннее название | Текст |
| Название для клиента | Текст |
| Порядок | Число |
| Цвет | Палитра |
| Ответственные роли | Мультивыбор |
| Видимость клиенту | Да / нет |
| Обязательные поля | Список custom fields |
| Обязательный комментарий | Да / нет |
| Обязательный файл | Да / нет |
| Следующие этапы | Граф |
| Уведомления | Правила |
| Ожидаемый срок | Необязательно |

### Клиентские настройки этапа (D-072)

- показывать этап;
- клиентское название;
- клиентское описание;
- обязателен ли комментарий менеджера перед публикацией.

### Настраиваемые поля (D-070)

Типы: текст, число, дата, список, файл, чекбокс, пользователь, компания.

Привязка: к типу объекта и/или к этапу.

### Кнопки

| Кнопка | Результат |
|---|---|
| Создать шаблон | Новый WorkflowTemplate |
| Новая версия | WorkflowTemplateVersion; старые объекты не меняются |
| Активировать версию | Новые объекты получают эту версию |
| Добавить этап | WorkflowStage в черновик версии |
| Настроить переходы | AllowedTransitions |
| Опубликовать версию | Версия становится доступной для новых объектов |
| Просмотреть аудит | ChangeAudit по шаблону |

### Состояния и ошибки

- нельзя удалить этап, на котором есть активные объекты;
- нельзя опубликовать версию без начального и финального этапа;
- переход без обязательных полей блокируется на экземплярах;
- изменение без причины блокируется.

### Ограничения

- Foundation Gate: read-only список и версии; создание/редактирование через UI не входит;
- последующий этап: упрощённый редактор, не полный BPMN (OQ-029, OQ-030);
- миграция существующих объектов на новую версию — OQ-031;
- внешние уведомления — позже (D-017).

### Критерии приёмки последующего редактора

- роль, утверждённая после OQ-030/OQ-044, создаёт и версионирует шаблон;
- новая версия не ломает историю старых объектов;
- права ролей на этап применяются при переходе;
- клиент видит только разрешённые этапы;
- аудит фиксирует каждое изменение с причиной.

## AD-002 — Пользователи и роли

Пользователи, memberships, несколько ролей и назначения в пределах tenant. Tenant admin не получает доступ к другим tenants или platform admin функциям.

## AD-003 — Журнал аудита

Все изменения процессов, этапов, прав и критических действий (D-069).

## Открытые вопросы

- OQ-030 — кто может редактировать шаблоны;
- OQ-031 — миграция между версиями;
- OQ-032 — дефолтные эскалации.
