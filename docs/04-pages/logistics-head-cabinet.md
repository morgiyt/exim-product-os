# Dashboard руководителя логистики

## LH-001 — Главная

### Цель

Дать руководителю логистики операционный контроль просчётов, сроков, перевозок и работы команды.

### Роли с доступом

- руководитель логистики;
- администратор (полный доступ).

### Блоки dashboard

- просчёты в работе и без ответа;
- сроки расчётов (без утверждённого SLA — OQ-021);
- перевозки в работе;
- активные проблемы и статус их решения;
- нагрузка и показатели каждого логиста;
- запросы, возвращённые логистом на уточнение;
- перевозки без свежего обновления;
- случаи без ставки от партнёров (OQ-028).

### Данные

- логист-исполнитель;
- менеджер-заказчик расчёта;
- возраст запроса / перевозки;
- выбранный и невыбранный варианты ставок;
- открытые проблемы и автор решения;
- отклонение от плановой даты.

### Кнопки и результат

| Кнопка | Результат |
|---|---|
| Открыть расчёт | Карточка запроса и варианты ставок |
| Открыть перевозку | Карточка перевозки и проблемы |
| Открыть логиста | Сводка работы сотрудника |
| Назначить перераспределение | Смена исполнителя с записью в аудит |

### Состояния и ошибки

- пустой dashboard при отсутствии данных;
- просрочка по внутреннему контрольному сроку без утверждённого SLA;
- проблема без решения дольше порога — подсветка (порог не утверждён).

### Ограничения

- dashboard не заменяет детальную карточку перевозки;
- точные статусы перевозки — OQ-026;
- способ tracking — OQ-027.

### Критерии приёмки

- руководитель видит все блоки из D-053;
- переходы ведут к реальным объектам;
- проблемы и их решения отображаются с автором;
- нагрузка по логистам агрегируется корректно.

### Открытые вопросы

- OQ-021 — точный SLA расчёта;
- OQ-026 — точные статусы перевозки;
- OQ-027 — как именно отслеживают груз;
- OQ-028 — что делать, если ни один партнёр не дал ставку.
