# Кабинет менеджера

## MG-001 — Главная

- новые обращения;
- запросы без логиста;
- расчёты с дедлайном;
- просроченные расчёты;
- перевозки без клиентского обновления;
- задержки;
- непрочитанные сообщения.

Dashboard должен вести к реальным объектам, а не показывать декоративные числа.

## MG-002 — Карточка клиента

Компания, БИН/ИИН, контакты, основной менеджер, запросы, предложения, перевозки, документы, чат и история.

## MG-003 — Карточка запроса

Клиент, источник, груз, маршрут, вложения, логист, дедлайн, расчёты, итоговая цена и следующее действие.

Кнопки: уточнить, назначить логиста, отправить на расчёт, вернуть, добавить маржу, сформировать предложение, отправить клиенту, закрыть с причиной.
