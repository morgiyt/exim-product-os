# Кабинет менеджера

## MG-001 — Главная

- новые лиды / обращения;
- запросы без расчёта;
- расчёты без ответа логиста;
- предложения без ответа;
- перевозки без клиентского обновления;
- задержки;
- изменения цен;
- непрочитанные сообщения.

Dashboard должен вести к реальным объектам, а не показывать декоративные числа.

## MG-002 — Карточка клиента

Компания, БИН/ИИН, контакты, пользователи компании, основной менеджер, временные передачи с заметками, запросы, предложения, сделки, годовые договоры, заявки к договору, перевозки, документы, чат и история.

Кнопка передачи клиента недоступна без заполнения: текущая ситуация, что согласовано, проблемы, следующие действия.

## MG-003 — Карточка запроса

Клиент, источник, обязательные поля груза, вложения, логист, версии расчётов, итоговая цена, маржа, история изменений цены и следующее действие.

Обязательные данные: откуда, куда, вес, дата готовности, штабелирование, размеры, способ погрузки, тип перевозки, фотографии. Упаковка и ТН ВЭД — по ситуации.

Кнопки: уточнить, назначить логиста, отправить на расчёт, вернуть, установить цену и маржу, запросить согласование низкой маржи, сформировать предложение, отправить клиенту, создать заявку к договору / перевозку, закрыть с причиной.

Числовой SLA расчёта не утверждён; внутренний контрольный срок — гипотеза H-002.
