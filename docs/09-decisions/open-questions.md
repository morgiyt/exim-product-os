# Открытые вопросы

Агент не закрывает их предположением. Ответ владельца процесса оформляется решением `D-*`, после чего вопрос переносится в закрытые.

## Вопросы Private OS, не блокирующие ограниченный Foundation Gate

Foundation Gate использует заранее заданные QuoteRequest/Shipment и минимальный Trip workflow, pre-created test accounts, tenant-admin scope и не включает Bitrix, billing, полное закрытие перевозки или редактор шаблонов. Поэтому вопросы ниже остаются важными для развития Private OS, но не дают интегратору права додумывать их и не блокируют описанный happy path Gate.
