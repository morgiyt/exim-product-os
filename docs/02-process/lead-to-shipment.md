# От лида до перевозки

```text
Сайт / бот / звонок / реклама / исходящий контакт
        ↓
Лид / обращение
        ↓
Менеджер создаёт клиента (или связывает нового отправителя запроса)
        ↓
Запрос на расчёт
  (менеджер или клиент)
        ↓
Менеджер передаёт запрос логисту
        ↓
Логист проверяет данные
  ├── не хватает → возврат менеджеру
  └── достаточно → поиск ставок
        ↓
Логист ищет ставки у партнёров и на площадках
  (FAFA, ATI.SU, Della и другие)
        ↓
Ставки и комментарий передаются менеджеру
        ↓
Менеджер устанавливает итоговую цену и маржу
  (низкая маржа → согласование с руководителем продаж)
        ↓
Менеджер и клиент выбирают вариант
        ↓
Коммерческое предложение / сделка
        ↓
Годовой договор (+ продление)
        ↓
Заявка EXIM с клиентом (подписание)
        ↓
Логист согласовывает с партнёром условия перевозки и оплаты
        ↓
Заявка логиста с партнёром (подписание)
        ↓
Менеджер вручную создаёт перевозку
  (ответственный логист = автор выбранного расчёта)
        ↓
Логист получает данные водителя
        ↓
Исполнение до конечной точки
  (проблемы решает логист по мере поступления)
        ↓
Tracking
  (плановая дата: перевозчик → логист → менеджер → клиент)
        ↓
Поэтапное закрытие:
  груз доставлен → АВР подписан → оплата получена → документы возвращены
```

| Этап | Ответственный |
|---|---|
| Лид, контакт, создание клиента | Менеджер |
| Запрос на расчёт | Менеджер или клиент |
| Передача запроса логисту | Менеджер |
| Проверка данных и возврат на уточнение | Логист |
| Поиск ставок у партнёров и площадок | Логист |
| Передача ставок менеджеру | Логист |
| Выбор варианта | Менеджер + клиент |
| Итоговая цена и маржа | Менеджер |
| Согласование низкой маржи | Руководитель продаж |
| Заявка EXIM с клиентом | Менеджер + юрист |
| Согласование с партнёром | Логист |
| Заявка логиста с партнёром | Логист |
| Создание перевозки | Менеджер |
| Данные водителя и исполнение | Логист |
| Решение проблем в пути | Логист |
| Публикация статусов клиенту | Менеджер |
| Оплата | Бухгалтер |
| Контроль воронки продаж | Руководитель продаж |
| Контроль просчётов и перевозок | Руководитель логистики |

## Данные для расчёта

**Минимум для начала расчёта логистом (D-042):**

- маршрут;
- груз;
- вес;
- объём.

**Расширенный запрос от продаж (D-025):** откуда, куда, вес, дата готовности, штабелирование, размеры, способ погрузки, тип перевозки, фотографии. Упаковка и ТН ВЭД — необязательны в некоторых случаях.

## Изменение цены

- до забора груза: цена может измениться при изменении данных по грузу; нужны причина и согласование клиента (D-051);
- после начала перевозки: ставка обычно не меняется (D-050);
- другие причины из продаж: изменение даты, неготовность, простой, неполные данные (D-030).

Каждая запись хранит: старую цену, новую цену, причину, автора, дату. Все версии расчётов сохраняются.

## Документы от завода

- инвойс;
- упаковочный лист;
- сертификаты;
- разрешительные документы.

## Плановая дата

Сообщает перевозчик логисту → логист менеджеру → менеджер клиенту. Изменяет менеджер. Старые даты сохраняются с причиной.

## Ограничения

- точный SLA расчёта не утверждён (OQ-021);
- что делать, если ни один партнёр не дал ставку — OQ-028;
- точные статусы перевозки — OQ-026;
- как именно отслеживают груз — OQ-027;
- момент приглашения клиента в приложение — H-001 / OQ-023;
- модель «одна перевозка / несколько рейсов» — OQ-024;
- полный набор условий закрытия сделки — OQ-025.
