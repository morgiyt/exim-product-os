# От лида до перевозки

```text
Сайт / бот / звонок / реклама / исходящий контакт
        ↓
Лид / обращение
        ↓
Менеджер создаёт клиента (или связывает нового отправителя запроса)
        ↓
Запрос на расчёт
  (менеджер или клиент; обязательные данные груза)
        ↓
Менеджер проверяет данные и передаёт логисту
        ↓
Логист возвращает цену и комментарий
  (что входит / не входит; версии расчётов сохраняются)
        ↓
Менеджер устанавливает итоговую цену и маржу
  (низкая маржа → согласование с руководителем продаж)
        ↓
Коммерческое предложение клиенту
  (клиент видит только итоговую цену и услуги)
        ↓
Сделка
        ↓
Годовой договор (+ продление)
        ↓
Заявка к договору на перевозку
        ↓
Менеджер вручную создаёт перевозку
  (ответственный логист = автор выбранного расчёта)
        ↓
Один или несколько рейсов
        ↓
Исполнение и tracking
  (плановая дата: перевозчик → логист → менеджер → клиент)
        ↓
Поэтапное закрытие:
  груз доставлен → АВР подписан → оплата получена → документы возвращены
```

| Этап | Ответственный |
|---|---|
| Лид, контакт, создание клиента | Менеджер |
| Запрос на расчёт | Менеджер или клиент |
| Закрепление нового клиента | Менеджер |
| Временная передача клиента | Менеджер + обязательная заметка |
| Себестоимость / цена логиста | Логист |
| Итоговая цена и маржа | Менеджер |
| Согласование низкой маржи | Руководитель продаж |
| Коммерческое предложение и сделка | Менеджер |
| Годовой договор и заявка к договору | Менеджер + юрист |
| Создание перевозки | Менеджер |
| Исполнение рейсов | Логист |
| Публикация статусов клиенту | Менеджер |
| Оплата | Бухгалтер |
| Контроль воронки и показателей | Руководитель продаж |

## Обязательные данные запроса на расчёт

- откуда;
- куда;
- вес;
- дата готовности;
- штабелирование;
- размеры;
- способ погрузки;
- тип перевозки;
- фотографии.

Упаковка и код ТН ВЭД — необязательны в некоторых случаях.

## Изменение цены

Причины: изменение даты, неготовность груза, простой, неполные данные, другие обстоятельства.

Каждая запись хранит: старую цену, новую цену, причину, автора, дату. Все версии расчётов сохраняются.

## Плановая дата

Сообщает перевозчик логисту → логист менеджеру → менеджер клиенту. Изменяет менеджер. Старые даты сохраняются с причиной.

## Ограничения

- точный SLA расчёта не утверждён (OQ-021);
- поведение при отсутствии цены от логиста не утверждено (OQ-022);
- момент приглашения клиента в приложение — гипотеза H-001 / OQ-023;
- модель «одна перевозка / несколько рейсов» vs отдельные перевозки — OQ-024;
- полный набор условий закрытия сделки — OQ-025.
