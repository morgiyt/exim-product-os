# Мастер-промпт для Cursor

Скопируй весь текст ниже и отправь агенту Cursor в открытой папке `exim-product-os`.

---

Ты работаешь с отдельным репозиторием `EXIM Product OS`. Это не рабочее приложение, а единый источник правды и визуальная спецификация продукта.

1. Прочитай полностью `README.md`, `AGENTS.md`, `docs/01-foundation/product-foundation.md`, `docs/09-decisions/open-questions.md`.
2. Не меняй бизнес-смысл документов.
3. Выполни `npm install`.
4. Выполни `npm run docs:build`.
5. Исправляй только технические ошибки VitePress, ссылок, конфигурации или Markdown.
6. После успешной сборки выполни `npm run docs:dev` и сообщи локальный адрес.
7. Проверь навигацию, страницы, таблицы, wireframe и изображения MVP.
8. Если Git не инициализирован: `git init && git branch -M main`.
9. Создай коммит `Initialize EXIM Product OS v0.1.0`.
10. Не создавай GitHub-репозиторий и не выполняй push без явного подтверждения пользователя.
11. Покажи результат сборки, список исправлений, структуру и статус Git.

Критически важно: не добавлять backend, БД или авторизацию; не придумывать функции; все сомнения записывать как открытые вопросы; соблюдать `AGENTS.md`.
